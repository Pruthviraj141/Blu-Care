## Core Constraints & Directives

1. **Scope Boundary**: Refactoring is strictly constrained to the `frontend/` directory. Backend API contracts (`/api/v1/session/start`, `/api/v1/session/message`) remain untouched.
2. **Zero AI Tells**: Eliminate neon glows, purple gradients, generic floating blobs, glassmorphism overuse, and cocktail bar legacy code.
3. **Clinical Trust**: Interface adopts a quiet, dense, high-contrast visual identity inspired by Linear and Stripe Climate.
